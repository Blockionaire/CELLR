# Physical iPhone acceptance checklist: scan → external suggestion → own wine (Sprint 004C)

The automated tests run in Chromium with phone and desktop viewports and a programmed label reader (`apps/web/e2e/scan-records.spec.ts`). These checks need a **real iPhone** (Safari and the installed home-screen app), a real camera, real light and a real connection. They are for the owner, in a staging environment or at activation step 10. A source must be `public` there, so in staging use a fictitious source, never X-Wines or LWIN before their rights are cleared.

**Setup:** iPhone with a current iOS, Safari, CELLR added to the home screen, a test household with a few wines, and one fictitious public source holding a wine you also have a printed "label" for (and one it does not hold).

| #   | Check                                                                              | Expected                                                                                                                                                               | ✓   |
| --- | ---------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --- |
| 1   | Open Scan from the home-screen app, allow the camera                               | Live camera; no browser chrome; the shutter is reachable with the thumb                                                                                                |     |
| 2   | Photograph the printed label of the source's wine (good light)                     | "A new wine" and below it **"Could be this wine"** with the producer, name, colour, country and region; one plain line "Source: … · licence … · not verified by CELLR" |     |
| 3   | The same in Dutch (Profile → Language → Nederlands)                                | "Een nieuwe wijn", "Mogelijk deze wijn", "Bron: … · licentie … · niet geverifieerd door CELLR"                                                                         |     |
| 4   | Tap **Use these details**                                                          | The form is filled in. The notice names the source and says it is not verified. Every field can be edited; the keyboard does not hide the Continue button              |     |
| 5   | Correct the wine name, then Continue → Add 1 bottle                                | "Added to your cellar"; the bottle's year is the one read off the label                                                                                                |     |
| 6   | Open the wine → Sources & reliability                                              | "The details were taken from this source when the wine was added; your household confirmed them", with the source's credit                                             |     |
| 7   | Airplane mode on, scan again and tap Continue                                      | "We couldn't reach CELLR…". Nothing is created; the form keeps its values. Airplane mode off → Continue works once (no duplicate wine)                                 |     |
| 8   | A blurry or dark photo of the label                                                | Either the form with "hard to read" and no suggestion, or a suggestion you can refuse. Never a wine added by itself                                                    |     |
| 9   | A label the source does not hold                                                   | No "Could be this wine" block at all                                                                                                                                   |     |
| 10  | A label of a wine already in the household                                         | "We found it" with your own wine; no external suggestion                                                                                                               |     |
| 11  | VoiceOver on: steps 2–5                                                            | The suggestion's heading, credit and button are read in order; the button says "Use these details"                                                                     |     |
| 12  | Text size at the largest Dynamic Type setting                                      | Nothing cut off; no horizontal scrolling                                                                                                                               |     |
| 13  | Dark mode                                                                          | Credit text readable; the card stands out from the page                                                                                                                |     |
| 14  | Switch the source off (Admin → External sources), then reopen the wine from step 6 | The credit is gone; the wine and bottle are still there                                                                                                                |     |
| 15  | Rotate the phone during step 4                                                     | The form keeps its values                                                                                                                                              |     |

Record: iPhone model, iOS version, date, staging or production, and a screenshot of steps 2, 4 and 6.
