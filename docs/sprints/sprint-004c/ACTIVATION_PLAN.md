## What stays true at every step

- Households' wines, bottles and tasting notes are never written by an import. Switching a source off removes its suggestions and credits only. A wine created from a record keeps its own data (R-27); only the credit disappears.
- Pilot data never reaches people: `catalog_search_pilot` refuses outside `pilot` / `staging` databases, and production is neither.
- The tools refuse the production project in every form. A production import is the owner calling the database functions themselves, as written in the runbook.
