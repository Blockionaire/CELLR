- `engines/hybrid.ts` (variants C and D), `guard-effect.ts` and `guard-study.ts` (variant E);
- `selection-study.ts`, `self-knowledge.ts`, `analyze.ts` and `expert-sheet.ts`;
- the S9 engine rule tuning.

They belong to work V1+ does not ship (closeout §4.4). They stay on their branches.

**Release configuration** (D-52):

- `packages/domain/src/sommelier-parts.ts` reads `CELLR_SOMMELIER`, a comma list of `check`, `annotate`, `quantities`,
  `menu` and `fallback`.
  - Empty or unset means none.
  - There is no `all`.
  - Unknown names are ignored, and returned for logging.
  - It is not part of `CELLR_FEATURES`.
- `server/env.ts` `getSommelierParts()` logs an unknown name once, by name only. `server/services.ts` passes the parts
  to the sommelier service.
- `SommelierDeps.parts` is a field that **no code reads yet**: each part's own PR (P3–P7) does.
- The register (1.4.1) names `CELLR_SOMMELIER` as an env gate of `svc-sommelier`.

## 4. Cost estimate for the paid baseline (nothing sent)

`pnpm sommelier:eval --engine v1-ai --estimate --set <set> --needs pairing,facts`. The estimate builds the prompts
with the app's own code, counts them, and prices them high: the full output allowance and one repair per call.

| Set                  | Calls | Tokens in / out (high) | High estimate per run |
| -------------------- | ----: | ---------------------: | --------------------: |
| main (133 attempted) |   131 |      340,592 / 117,900 |               $0.2031 |
| holdout-dev          |    45 |       105,293 / 40,500 |               $0.0668 |
| holdout-test (blind) |    43 |       102,134 / 38,700 |               $0.0643 |
| **All three**        |   219 |                        |           **$0.3342** |

**Against what was paid before.** S9 ran these three sets five times for $0.0961, about $0.02 per run of all three.
The high estimate is therefore about 15× the real price; the gap comes from output allowance and repairs.

**Proposed baseline**, to be approved (D-51): V1 with AI, three runs of the three sets, with per-scenario vectors
committed.

- High estimate: **$1.00**.
- Expected from S9's price: **about $0.06**.
- A hard stop: `--max-usd 1.00`.
- That uses at most a third of the proposed $3. The rest is for P3 and P6, the two parts V1's model sees.
